# CapacitorManager 1.0.0-rc.21

## Desempenho e navegação

Esta versão reduz a espera ao abrir a aplicação e trocar de página, sem alterar
cadastros, medições ou resultados dos relatórios.

- a sessão do navegador é restaurada localmente e o perfil do usuário é
  carregado uma única vez pelo provedor de autenticação;
- a proteção do servidor valida o JWT com `getClaims`, mantendo a checagem de
  perfil e assinatura nas rotas privadas;
- o menu deixa de disparar antecipadamente todas as páginas privadas e suas
  respectivas validações;
- o menu público permanece utilizável enquanto o acesso privado é verificado;
- Clientes, Bancos, Capacitores, Medições, Dimensionamento, Medições dos Trafos
  e Configurações reutilizam o perfil já carregado;
- consultas independentes passam a executar em paralelo;
- Bancos deixa de executar uma consulta de capacitores para cada banco;
- o Dashboard elimina a busca complementar de um capacitor por medição, reduz
  o volume das colunas transferidas e carrega os parâmetros em uma única
  consulta;
- a Lixeira carrega suas três categorias em paralelo.

## Integridade funcional

- nenhuma migração de banco de dados é necessária;
- a exclusão dos quatro capacitores do POSTE-B é respeitada: o banco permanece
  com zero componentes ativos e cobertura de 0%;
- cálculos, classificação, tendências, paginação de relatórios, importadores e
  proteção de rotas permanecem cobertos pela suíte automatizada.

## Validação

- 73 testes automatizados aprovados;
- sintaxe TypeScript/TSX validada nos arquivos alterados;
- pacote de entrega não inclui `.env.local`, cache `.next`, `node_modules` nem
  arquivos de controle de versão.

Em desenvolvimento, a primeira abertura de uma página ainda pode levar alguns
segundos porque o Next.js compila a rota sob demanda. O build de produção não
tem essa etapa durante a navegação do usuário.
