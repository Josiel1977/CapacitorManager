# CapacitorManager 1.0.0-rc.15

## Relatórios mais compactos

- A página de tendências comporta até 11 capacitores.
- O detalhamento comporta até 18 medições por página.
- A paginação distribui os registros de forma equilibrada e evita uma última página com apenas um item.
- Para o conjunto observado na homologação, a quantidade de páginas deve cair de forma relevante sem quebrar o formato A4.

## Navegação mais leve

- `jsPDF` e `html-to-image` passam a ser carregados somente quando o usuário solicita uma exportação.
- A otimização foi aplicada em Relatórios, Gráficos, Análise de Massa e Dimensionamento.
- Uma tela de carregamento global fornece retorno visual imediato durante transições que ainda dependem da rede.
- Em desenvolvimento, o primeiro acesso a cada rota ainda inclui compilação sob demanda; a aferição final deve ser feita com o build de produção.

## Validação

- 66 testes automatizados aprovados.
- Novos testes cobrem distribuição equilibrada, limite por página e coleção vazia.
