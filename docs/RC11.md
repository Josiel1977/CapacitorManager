# CapacitorManager 1.0.0-rc.11

## Correção da Demo de fatura

- Respostas vazias ou inválidas da API não provocam mais `Unexpected end of JSON input`.
- Erros HTTP agora são convertidos em mensagens compreensíveis.
- O processamento possui limite de 35 segundos e mensagem própria para timeout.
- No ambiente local, a Demo possui contingência de leitura no navegador quando o serviço servidor não está configurado.
- O limitador local funciona sem exigir a chave administrativa do ambiente de produção.
- Em produção, `SUPABASE_SECRET_KEY` e `RATE_LIMIT_SALT` continuam obrigatórios.
- A montagem do resultado comercial passou a usar uma única função compartilhada entre servidor e contingência local.

## Identificação de documentos

- Classificação automática entre fatura Equatorial, relatório Embrasul e documento desconhecido.
- “Medições dos Trafos” continua aceitando somente dados do analisador Embrasul.
- Uma fatura Equatorial enviada nessa tela agora é identificada corretamente e direcionada à Demo/Auditoria, sem erro genérico de P, Q e S.
- Os textos e botões da tela deixam explícito que o PDF deve ser do Embrasul.
