# CapacitorManager 1.0.0-rc.20

## Correção do POSTE-B

O histórico do POSTE-B permanece vinculado a identificadores anteriores do banco e, possivelmente, dos capacitores. O RC19 recuperava uma relação vazia, mas ainda filtrava as medições exclusivamente pelo identificador atual.

O RC20 reconcilia de forma controlada:

- identificador legado do banco com o cadastro ativo, pelo nome normalizado;
- identificador legado do capacitor com o componente atual, pelo código de identificação;
- variações equivalentes como `POSTE-B`, `POSTE B` e espaços excedentes;
- somente correspondências únicas, sem adivinhar quando existem nomes duplicados.

## Segurança dos dados

- Nenhum registro do banco é alterado no Supabase.
- A reconciliação ocorre apenas na leitura do relatório.
- Capacitores explicitamente inativos continuam excluídos.
- Bancos homônimos não são mesclados automaticamente.

## Validação

- 73 testes automatizados aprovados.
- Cenário real reproduzido com CPB-01, CPB-02, CPB-03 e CPB-04.
- Resultado esperado validado: quatro aprovados e cobertura de 100%, tanto com ativos atuais quanto apenas com vínculos legados.
