# CapacitorManager 1.0.0-rc.22

## Gráficos

- A comparação do banco passa a ler as medições de forma compatível com bases
  que ainda não possuem a coluna opcional de frequência.
- Quando a frequência estiver registrada, ela continua sendo utilizada; quando
  não estiver, o cálculo mantém o padrão de 60 Hz.
- Erros retornados pelo Supabase agora são preservados na mensagem e no console,
  facilitando um diagnóstico preciso em vez do aviso genérico.

## Manutenção Preditiva

- Removida a consulta à coluna legada `data_medicao`.
- A data oficial volta a ser `created_at`, conforme a estrutura atual da tabela
  `medicoes`.
- A leitura permanece compatível com instalações anteriores e conserva a
  seleção da medição mais recente de cada tipo por capacitor.
- O Dashboard utiliza a mesma leitura compatível para não repetir a falha.

## Configurações

- A aba interna de manutenção também foi migrada dos nomes antigos
  `data_medicao`, `tipo_medicao` e `desvio_percent` para os campos atuais.

## Validação

- 76 testes automatizados aprovados.
- Incluídos testes contra regressão do esquema de medições.
- Nenhuma migração de banco de dados é necessária para esta correção.
- Nenhum cadastro ou histórico foi alterado.
